# 홍보 사이트 시트 명세

> Google Sheets **1개**. 관문(Apps Script)이 이 시트에 붙어 있다. 공유하지 않으며 관문을 통해서만 쓴다.
> 아카이빙 시트와 별개다(`docs/decisions.md` 3절).

---

## 1. 확정 사항

| 항목 | 규칙 |
|---|---|
| 시트 | 1개 (관문이 붙어 있는 시트) |
| 탭 | 읽어보기 · 공지 · 갤러리 · 첨부 · 접근코드 · 설정 · 로그 · 언론홍보 · 표지 (언론홍보 · 표지는 2026-10-14 추가 — 이미 있는 시트에서는 `setup()`이 맨 뒤에 붙임) |
| 입력 | 공지 · 언론홍보 · 갤러리 · 표지 · 첨부는 **관리자 페이지에서만** 쓴다. 시트에서 직접 고치지 않는다 |
| 글ID | 자동 생성. 공지 `N-0001`, 언론홍보 `P-0001`, 갤러리 `G-0001` (앞자리로 게시판을 구분). 표지는 고정 칸 `H-dance` · `H-music` · `H-art` · `H-trad` |
| 공개여부 | 공개 · 비공개 |
| 공개 파일 | `data/posts.json` (3절) — 공개 글만 담아 관문이 저장소에 커밋 |

---

## 2. 탭

| 탭 | 입력 | 역할 |
|---|---|---|
| 읽어보기 | 안내 | 시트를 직접 고치지 말라는 안내, 탭 설명 |
| 공지 | 관리자 페이지 | 공지 한 건이 한 줄 |
| 갤러리 | 관리자 페이지 | 앨범 한 개가 한 줄 |
| 언론홍보 | 관리자 페이지 | 기사 한 건이 한 줄 (2-7) |
| 표지 | 관리자 페이지 | 분야 칸 하나가 한 줄, 4줄 고정 (2-8) |
| 첨부 | 관리자 페이지 | 사진 · 파일 한 개가 한 줄. 글ID로 공지 · 갤러리 · 표지와 연결 |
| 접근코드 | 직접 | 운영진 한 사람당 한 줄 |
| 설정 | 직접 | 항목-값. 분류 목록, 실패 제한 등 |
| 로그 | **자동** | 로그인 · 저장 · 삭제 · 업로드 · 발행 기록 |

**탭 이름과 열 이름은 함부로 바꾸지 않는다.** 관문은 탭과 열을 이름으로 찾는다(아카이빙에서 탭 이름을 바꿔 로그인이 전부 멈춘 사례가 있음).

### 2-1. 공지

| 열 | 값 | 비고 |
|---|---|---|
| 글ID | `N-0001` | 자동 |
| 분류 | 「설정」의 공지 분류 중 하나 | |
| 제목 | | 필수, 200자 이내 |
| 본문 | 일반 글 | 줄바꿈 유지, 5,000자 이내. 서식은 `**굵게**` · `{강조:…}` · `{빨강:…}` 기호로 글자 그대로 저장 (`decisions.md` 4절) |
| 게시일 | `2026-09-02` | 화면 표시 · 정렬 기준. 기본값은 작성일 |
| 상단고정 | `예` · 빈칸 | 확인 필요 — 사용 여부 (`decisions.md` 4절) |
| 사진위치 | `위` · `아래` | 기본 `위` (사진 → 글) |
| 사진링크 | `https://…` | 사진을 누르면 이동할 주소. 비우면 사진을 누르면 확대 보기 |
| 공개여부 | `공개` · `비공개` | |
| 작성자 · 작성시각 | | 자동. 작성자는 「운영자」(2026-10-14부터 이름 칸 없음) |
| 수정자 · 수정시각 | | 자동 |

### 2-2. 갤러리

| 열 | 값 | 비고 |
|---|---|---|
| 글ID | `G-0001` | 자동 |
| 제목 | `무용 워크숍 현장` | 필수, 100자 이내 |
| 설명 | `2026.07 · 광주캠퍼스` | 촬영 시기 · 장소. 목록 제목 아래 한 줄 |
| 게시일 | `2026-07-20` | 정렬 기준 |
| 공개여부 | `공개` · `비공개` | |
| 작성자 · 작성시각 · 수정자 · 수정시각 | | 자동 |

대표 사진은 「첨부」에서 순서가 가장 앞인 사진이다.

### 2-3. 첨부

| 열 | 값 | 비고 |
|---|---|---|
| 첨부ID | `A-00001` | 자동 |
| 글ID | `N-0001` · `G-0001` · 빈칸 | 올리기만 하고 아직 글에 저장하지 않은 파일은 빈칸 |
| 구분 | `사진` · `파일` · `누끼` | 갤러리는 `사진`만. `누끼`는 표지 2.5D용 투명 배경 PNG(표지만, 2026-10-15) |
| 순서 | 1, 2, 3 … | 화면 표시 순서 |
| 파일ID | Drive 파일 ID | |
| 파일명 | 원래 이름 | 내려받을 때 이 이름으로 받아짐 |
| 크기 | 바이트 | 첨부 목록에 `160K`처럼 표시 |
| 가로 · 세로 | 픽셀 | 사진 · 누끼만. 화면이 자리를 미리 잡아 덜컹거림을 막음. 누끼는 원본 사진과 같아야 함 |
| 공유 | `공유` | 자동. 올리는 즉시 「링크가 있는 사용자」로 공유 (`decisions.md` 5절) |
| 올린사람 · 올린시각 | | 자동 |

- 글을 삭제하면 그 글의 첨부 파일은 드라이브 **휴지통**으로 보낸다(30일 안에 드라이브에서 복구 가능).
- 글ID가 빈칸인 채 하루가 지난 파일은 정리 대상이다. 정리 방식(자동 · 수동)은 **확인 필요**.

### 2-4. 접근코드

| 열 | 비고 |
|---|---|
| 코드 | 무작위 문자열 (아카이빙 코드와 겹치지 않게 앞부분을 `HP-`로 시작, 예: `HP-XXXX-XXXX`) |
| 이름 | 코드 설명용 라벨 (예: 운영진 공용). 작성자 기록에는 쓰지 않는다 |
| 상태 | `사용` · `정지` |
| 사용기한 | `2027-03-31` 등. 확인 필요 |
| 버전 | 올리면 그 코드의 모든 접속이 즉시 끊김 |
| 비고 | |

> 실제 코드 값은 이 문서에 쓰지 않는다. `docs/private/`에만 둔다.
> 운영진이 함께 쓰는 공용 코드다. 관리자 화면에 이름 칸이 없어 작성자는 「운영자」로 기록된다 (`decisions.md` 6절). 사람을 구분하려면 사람마다 코드를 따로 준다(「로그」 탭에 코드가 남음).

### 2-5. 설정

항목-값 구조. 값이 비어 있으면 관문의 기본값을 쓴다.

| 항목 | 기본값 | 쓰임 |
|---|---|---|
| 공지 분류 | `공지,워크숍,심화과정` (2026-10-14 「아카이브」 삭제) | 쉼표로 구분. 관리자 페이지 분류 선택 목록 |
| 기기별 실패 잠금 기준 | `5` | `api.md` 6절 |
| 기기별 잠금 시간(분) | `10` | |
| 운영진 알림 메일 | (비움) | 실패 급증 · 발행 실패 시 메일. 비우면 보내지 않음 |

### 2-7. 언론홍보 (2026-10-14)

| 열 | 값 | 비고 |
|---|---|---|
| 글ID | `P-0001` | 자동 |
| 언론사 | `연합뉴스` | 필수, 50자 이내. 목록에서 제목 앞에 보임 |
| 제목 | 기사 제목 | 필수, 200자 이내 |
| 게시일 | `2026-10-14` | 정렬 기준 (기사 날짜) |
| 기사주소 | `https://…` | 필수, 500자 이내, http(s)만. 목록에서 누르면 새 탭으로 열림 |
| 공개여부 | `공개` · `비공개` | |
| 작성자 · 작성시각 · 수정자 · 수정시각 | | 자동 |

사진 · 첨부는 없다.

### 2-8. 표지 (2026-10-14)

| 열 | 값 | 비고 |
|---|---|---|
| 글ID | `H-dance` · `H-music` · `H-art` · `H-trad` | `setup()`이 4줄을 만든다. 새로 만들거나 지우지 않는다 |
| 칸 | `무용` · `음악` · `미술` · `전통예술` | 관리자 화면 표시용 |
| 작성자 · 작성시각 · 수정자 · 수정시각 | | 자동 (작성자 · 작성시각은 빈칸으로 남음) |
| 입체효과 | `예` · 빈칸 | 2.5D 입체 효과를 켰으면 `예` (2026-10-15 추가 — 이미 있는 탭에는 `setup()`이 맨 뒤에 붙임) |
| 입체중심 | `62.7,55.3` · 빈칸 | 확대 중심(사진 가로 · 세로의 %). 관리자 화면이 누끼의 인물 영역을 감싸는 상자의 가운데로 계산. 누끼가 없으면 빈칸 |

- 사진은 「첨부」에 글ID `H-…`로 **한 장만** 붙는다. 바꾸면 예전 사진은 휴지통으로.
- 2.5D를 쓰는 칸은 누끼(구분 `누끼`)도 한 장 붙는다. 입체효과가 `예`이려면 누끼가 있어야 하고 원본과 크기가 같아야 한다. **원본을 빼거나 바꾸면 누끼도 휴지통으로 가고 입체효과가 꺼진다** (2026-10-15 사용자 결정). 입체효과를 끄기만 하면 누끼는 남는다.
- 표지는 이 순서(무용 → 음악 → 미술 → 전통예술)로 넘어간다. 사진이 없는 칸은 사이트의 기본 사진(`main.css --img-hero-*`)을 쓰고, 기본 사진도 없으면 건너뛴다.

## 3. 공개 파일 `data/posts.json`

관문이 저장 · 삭제 · 공개 전환 때마다 다시 만들어 저장소에 커밋한다. **공개 글만** 담고, 작성자 · 시각 · 공유 상태 같은 관리용 값은 넣지 않는다.

```json
{
  "updatedAt": "2026-10-13T15:00:00+09:00",
  "notices": [
    {
      "id": "N-0003",
      "category": "심화과정",
      "title": "심화과정 참여 수요조사 안내",
      "body": "기간: 9.2 ~ 9.12\n응답: https://forms.gle/…",
      "date": "2026-09-02",
      "pinned": false,
      "photoPosition": "top",
      "photoLink": "https://forms.gle/…",
      "photos": [ { "fileId": "…", "w": 1600, "h": 2263 } ],
      "files":  [ { "fileId": "…", "name": "[양식] 참여신청서.hwp", "size": 163840 } ]
    }
  ],
  "press": [
    { "id": "P-0001", "source": "연합뉴스", "title": "K예술영재 프로젝트 개막", "date": "2026-10-14", "url": "https://…" }
  ],
  "gallery": [
    {
      "id": "G-0001",
      "title": "무용 워크숍 현장",
      "desc": "2026.07 · 광주캠퍼스",
      "date": "2026-07-20",
      "photos": [ { "fileId": "…", "w": 1600, "h": 1067 } ]
    }
  ],
  "hero": {
    "dance": { "fileId": "…", "w": 2400, "h": 1164, "fg": { "fileId": "…" }, "depth": { "x": 62.7, "y": 55.3 } },
    "art":   { "fileId": "…", "w": 2400, "h": 1597 }
  }
}
```

| 규칙 | 내용 |
|---|---|
| 정렬 | 공지: 상단고정 먼저, 그다음 게시일 최신순(같으면 글ID 큰 순). 언론홍보 · 갤러리: 게시일 최신순 |
| 표지 | `hero`는 사진을 올린 칸만 `{ dance · music · art · trad: 사진 }`. 표지는 공개여부가 없고 늘 공개. 2.5D를 켠 칸만 `fg`(누끼) · `depth`(확대 중심 %)가 붙는다 |
| 필드명 | 시트 열(한글)을 영어 camelCase로 옮긴다. `photoPosition`은 `top` · `bottom` |
| 빈 값 | 사진 · 파일이 없으면 빈 배열, 본문 · 링크가 없으면 빈 문자열 |
| 파일이 없을 때 | 화면은 "등록된 글이 없습니다"를 보인다 (발행 전 첫 배포 상태) |

## 4. 업로드 규칙

| 항목 | 사진 | 파일 |
|---|---|---|
| 형식 | jpg · png · webp (올리기 전에 JPEG로 변환. 표지 누끼는 png · webp를 받아 PNG로 둠) | hwp · hwpx · doc · docx · pdf · xls · xlsx · ppt · pptx |
| 크기 | 브라우저가 긴 변 1600px로 줄인 뒤 올림 (표지 사진은 2400px, 누끼는 원본 사진 크기로 맞춤 · 한 개 8MB 이하) | 한 개 10MB 이하 (보통 100~200KB) |
| 개수 | 공지 한 건 10장 · 갤러리 앨범 하나 50장 · 표지 칸 하나 1장(+ 누끼 1장) | 공지 한 건 10개 |

개수 · 용량 한도는 **확인 필요** — 임시값이며 실제 운영 자료를 보고 조정한다.
