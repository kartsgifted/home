페이지 텍스트각 페이지의 문구를 한 화면에서 수정합니다.

사용 방법정적 사이트라 저장은 content.json 파일로 이루어집니다.

편집 → 반영까지

1. 이 관리자 화면이나 각 페이지의 ?edit=1 인라인 편집 모드에서 내용을 고칩니다.
2. 임시 저장을 누르면 이 브라우저에만 저장되어 나만 미리 볼 수 있습니다.
3. content.json 내보내기로 파일을 받아 사이트 최상위 폴더(index.html 옆)에 덮어씁니다.
4. GitHub에 올리면 모든 방문자에게 반영됩니다.
주의 — 임시 저장은 이 브라우저에만 남습니다. 다른 PC나 시크릿 창에서는 보이지 않으니, 작업이 끝나면 반드시 content.json 을 내보내 올려주세요.
파일을 열 때 — 로컬에서 파일 더블클릭(file://)으로 열면 브라우저 보안 정책 때문에 페이지 텍스트를 불러오지 못합니다. VS Code Live Server 같은 로컬 서버나 GitHub Pages 주소로 열어주세요.
